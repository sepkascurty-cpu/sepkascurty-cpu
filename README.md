# Halo, Saya sepka! 👋

### Cloud Engineer & Cloud Security Engineer | DevSecOps Enthusiast

Saya adalah seorang praktisi di bidang **Cloud Engineering** dan **Cloud Security** dengan fokus pada perancangan arsitektur cloud yang aman, andal (*scalable*), serta efisien biaya (khususnya di ekosistem **AWS**). 

Saya menggabungkan pemahaman mendalam tentang keamanan siber (offensive & defensive) dengan praktik infrastruktur modern seperti **Infrastructure as Code (IaC)**, otomasi CI/CD, dan hardenings sistem Linux.

---

### ☁️ Fokus Utama & Keahlian Teknikal

* **Cloud Architecture & Engineering:** Merancang dan mengimplementasikan infrastruktur AWS yang *production-ready* (VPC, EC2, ECS, Lambda, CloudFront, S3, RDS) dengan prinsip *high availability* dan *cost optimization*.
* **Cloud Security & DevSecOps:** Menerapkan keamanan berlapis (*Defense-in-Depth*), pengelolaan IAM (Least Privilege), VPC Security Groups/NACLs, audit kerentanan infrastruktur, dan keamanan jaringan.
* **Infrastructure as Code & Automation:** Mengotomatiskan penyebaran infrastruktur menggunakan Terraform/CloudFormation dan scripting Python/Bash.
* **Linux System Administration:** Pengelolaan server Linux, *kernel auditing*, serta pemeliharaan keamanan sistem.
