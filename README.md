## About Me

I'm a student and technology enthusiast focused on building a career in **Cloud Engineering** and **Cloud Security Engineering**.

My current learning path combines **cloud infrastructure, networking, Linux, automation, and cybersecurity**. I enjoy learning by building projects, practicing in labs, and understanding how systems work from the infrastructure level up.

### Current Focus

- ☁️ Cloud Engineering
- 🔐 Cloud Security
- 🌐 Networking & Infrastructure
- 🐧 Linux & System Administration
- ⚙️ Cloud Automation & CLI
- 🛡️ Cyber Security fundamentals
- 📚 Continuous learning and hands-on projects

### Cloud Journey

Currently exploring and practicing:

- **AWS** — EC2, VPC, IAM, S3, RDS, Load Balancing, Auto Scaling
- **Networking** — IPv4/IPv6, CIDR, subnetting, routing, public/private networks
- **Linux** — command line, permissions, processes, services and system administration
- **Security** — IAM, security groups, least privilege, network security and cloud security fundamentals
- **Tools** — Git, GitHub, AWS CLI and Linux CLI
